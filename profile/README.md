## ⚡ Quick Start

Green Hell has a PC debug mode with shortcuts for god mode, item spawning, time control, and other gameplay options.

1. Back up your save before enabling debug features.
2. Open the game's installation directory and navigate to `GH_Data/Resources`.
3. Create the folders `scripts/Debug`, then place an empty file named `DEBUG` inside the Debug folder. Launch the game and load a save to try the documented shortcuts.
